# Portal de Horas Sociales

Repositorio del portal para gestionar horas sociales. La base utiliza Go, React, TypeScript, Tailwind, PostgreSQL y Docker.

**`main` permanece reservada y contiene únicamente este README.** El código completo está directamente en la raíz de [`develop`](https://github.com/Luisnativii/ServicioHorasSociales/tree/develop), la rama predeterminada de trabajo.

- [Proyecto e instrucciones de Docker](https://github.com/Luisnativii/ServicioHorasSociales/tree/develop#readme)
- [Guía de GitFlow, issues, ramas y versiones](https://github.com/Luisnativii/ServicioHorasSociales/blob/develop/docs/GITFLOW.md)
- [Crear un issue](https://github.com/Luisnativii/ServicioHorasSociales/issues/new/choose)
- [Pipelines](https://github.com/Luisnativii/ServicioHorasSociales/actions)
- [Base inicial V0.0.1](https://github.com/Luisnativii/ServicioHorasSociales/tree/V0.0.1)

Cada tarea parte de un issue y de una rama `tipo/NUMERO-descripcion`; sus pull requests se integran en `develop` mediante squash después de pasar CI. Las versiones se registran con tags `VMAJOR.MINOR.PATCH`. Todavía no hay despliegue en producción.
