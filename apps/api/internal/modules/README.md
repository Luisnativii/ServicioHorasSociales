`admin/` implementa persistencia del único rol ADMIN con múltiples cuentas. `repository.go` usa consultas generadas de `db/`, normaliza/valida correo y traduce errores sin revelar SQL. El hash se excluye de JSON y no se consulta en listados. Los handlers futuros deben usar DTOs explícitos, nunca serializar modelos SQL.

`cmd/admin` implementa altas exclusivamente por herramienta Docker con el hashing de `internal/platform/password`. No hay todavía JWT, login ni módulos de negocio. `scripts/check-admin.sh` prueba el repositorio con PostgreSQL real y rollback; `check-admin-cli.sh` comprueba el CLI y retira solo las cuentas sintéticas creadas por esa ejecución en hs-test. Las pruebas sin indicador explícito no conectan a desarrollo.
